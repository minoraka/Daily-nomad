# Как запустить Student Board

## 1. Установите (один раз)

- **Python 3.12 или новее**: https://www.python.org/downloads/
  На Windows при установке поставьте галочку **«Add python.exe to PATH»**.
- **Node.js 20 или новее** (LTS): https://nodejs.org/
- **Git**, чтобы скачать проект: https://git-scm.com/
  Можно и без Git: на GitHub нажмите **Code → Download ZIP** и распакуйте архив.

Проверка в терминале: `python --version` (на macOS/Linux `python3 --version`) и `node --version`.

## 2. Скачайте проект

```bash
git clone https://github.com/minoraka/Daily-nomad.git
cd Daily-nomad
```

## 3. Запустите

**Windows:** дважды щёлкните `start.bat` (или выполните `start.bat` в терминале в папке проекта).

**macOS / Linux:**

```bash
./start.sh
```

Первый запуск занимает 1–3 минуты: скрипт ставит зависимости, создаёт базу и демо-данные.
Следующие запуски проходят за несколько секунд.

## 4. Откройте сайт

- Сайт: http://localhost:5173
- Админка Django: http://localhost:8000/admin

Демо-аккаунты (у всех пароль `demo12345`):

| Логин | Кто |
|---|---|
| `student1` … `student3` | студенты потока ИС-21 |
| `student4` … `student6` | студенты потока ИС-22 |
| `demo_teacher` | преподаватель (только просмотр) |

Можно зарегистрировать новый аккаунт на странице входа.

### Попробовать проверку задач

1. Войдите как `demo_teacher` → **Доска** → **+ Задача** → «Весь поток» → **Назначить**.
2. В другом браузере (или в режиме инкогнито) войдите как `student1`: задача с иконкой 🎓 появилась в «Планирую».
   Перетащите её в «На проверке» (в «Готово» студент перенести не может).
3. Преподаватель открывает карточку → **Вернуть в работу** с комментарием или **Принять**.

## 5. Остановить

- macOS / Linux: `Ctrl+C` в терминале.
- Windows: закройте оба окна (основное и «Student Board - backend»).

## Админка: как добавить поток

1. Создайте администратора (один раз):
   - Windows: `cd backend` → `.venv\Scripts\python manage.py createsuperuser`
   - macOS / Linux: `cd backend` → `.venv/bin/python manage.py createsuperuser`
2. Откройте http://localhost:8000/admin и войдите.
3. **Groups → Add**, введите название потока (например `ИС-23`) и сохраните.
   Новые студенты смогут выбрать этот поток при регистрации.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| `python` или `npm` не найден | Установите Python / Node.js (шаг 1). После установки откройте терминал заново. |
| `Port 5173 is in use` или `8000 already in use` | Сайт уже запущен в другом окне: закройте его или перезагрузите компьютер. |
| `./start.sh: Permission denied` | Выполните `chmod +x start.sh` и запустите снова. |
| Хочу начать с чистой базы | Удалите файл `backend/db.sqlite3` и запустите скрипт снова. |
| Нужен скрипт без демо-данных | Удалите строку с `seed_demo` из `start.sh` / `start.bat`. |
